# Quickstart

This guide takes you from a fresh install to a running worker with a real background job. You'll define a task, discover it, queue it, and execute it — all locally, no external services required.

## 1. Install Nuvom

```bash
pip install nuvom
```

## 2. Define a task

Create a file called `tasks.py` in your project root:

```python
from nuvom.task import task

@task(retries=2, retry_delay_secs=5, timeout_secs=3, store_result=True)
def add(x, y):
    return x + y
```

The `@task` decorator turns `add` into a Nuvom task. The parameters configure retry behavior, a timeout, and result persistence — all optional, all explicit.

## 3. Discover tasks (recommended)

Nuvom uses AST-based static discovery to find tasks without executing your code. Run this once to generate the manifest:

```bash
nuvom discover tasks
```

This writes `.nuvom/manifest.json`, which speeds up worker startup and keeps task registration safe.

## 4. Queue a job

In a Python script or REPL, dispatch the task immediately:

```python
from tasks import add

job = add.delay(5, 7)
print(job.id)
```

`delay()` places the job in the queue and returns a job object with an ID you can use for inspection.

## 5. Start the worker

In a terminal, start the worker pool:

```bash
nuvom runworker
```

The worker picks up queued jobs and executes them. It respects the retry and timeout settings you defined on the task.

## 6. Inspect the result

Once the job is complete, inspect it by ID:

```bash
nuvom inspect job <job_id>
```

This shows the full job metadata, return value, and any traceback if it failed.
